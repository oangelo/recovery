# AGENTS.md

## Diretrizes de Documentação

### Hardware photos
- **Localização:** docs/imagens/
- **Nomenclatura:** nomes descritivos com versão + ângulo, sem espaços
  - Exemplo: `caixa_v1_frontal_superior.jpg`
- **Compressão:** `convert input.jpg -resize 1200x -quality 80 -strip output.jpg`
- **Layout em docs:** HTML tables para imagens lado a lado (3 por linha, 300px width), imagens isoladas em 500px
